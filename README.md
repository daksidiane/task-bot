# Таск-трекер в Telegram с голосовым вводом

Проблема бизнеса: Задачи ставили хаотично: писали на доске или раздавали на бегу. Поручения терялись, с исполнителями возникала путаница.

Бот принимает голосовое или текст, создаёт задачу, следит за сроком и показывает каждому сотруднику только его список. Администратор видит общую картину.

Бизнес получает контроль вместо записей на доске. У каждого поручения есть ответственный и срок.

## Установка и запуск

Нужны Python 3.10+ и токен бота от [@BotFather](https://t.me/BotFather).

```cmd
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Голос (по желанию):

```cmd
pip install -r requirements-ai.txt
```

Секреты кладите в `secrets/` — папка в git не попадает:

```cmd
mkdir secrets
copy .env.example secrets\.env
```

В `secrets/.env` заполните:

| Поле | Что вписать |
|---|---|
| `TG_BOT_TOKEN` | токен от BotFather |
| `ADMIN_IDS` | ваш Telegram ID, узнать: [@userinfobot](https://t.me/userinfobot) или команда `/myid` у бота |
| `CUSTOMER_IDS` | кто ставит задачи; пусто — те же, что админы |

Проверка и запуск:

```cmd
python main.py --check
python main.py
```

Голосовой ввод без отдельной модели работает ограниченно: бот соберёт черновик по правилам. Полный разбор формулировки — если на компьютере запущена локальная языковая модель (Ollama). Если её нет, бот всё равно создаёт задачу после подтверждения.

## Как пользоваться

1. Админ: `/staff` — добавить сотрудников (имя и Telegram ID).
2. Заказчик пишет задачу текстом или голосом. Перед отправкой подтверждает формулировку, исполнителя и срок.
3. Исполнитель видит карточку и закрывает задачу кнопками или `/done`.
4. Бот напоминает до срока и сообщает, если срок сорван.

Полезные команды: `/tasks`, `/log`, `/new`, `/staff`, `/myid`.
