# Таск-трекер в Telegram с голосовым вводом

Задачи ставили хаотично: писали на доске или раздавали на бегу. Поручения терялись, с исполнителями возникала путаница.

Бот принимает голосовое или текст, создаёт задачу, следит за сроком и показывает каждому сотруднику только его список. Администратор видит общую картину.

Бизнес получает контроль вместо записей на доске. У каждого поручения есть ответственный и срок.

## Как попробовать

Нужны Windows, [Python](https://www.python.org/downloads/) версии 3.10 или новее и Telegram.

При установке Python поставьте галочку **Add python.exe to PATH** внизу окна. Иначе следующие шаги не сработают.

1. На этой странице нажмите **Code** → **Download ZIP** и распакуйте архив.
2. Создайте бота в Telegram: откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, придумайте имя. BotFather пришлёт длинный токен — сохраните его.
3. Узнайте свой номер в Telegram: напишите [@userinfobot](https://t.me/userinfobot). Он ответит цифрами. Это ваш ID.
4. В папке проекта откройте чёрное окно команд: кликните по адресной строке Проводника, напишите `cmd`, Enter.
5. Введите по очереди, каждый раз Enter:

```cmd
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Первый `pip` может занять несколько минут.

6. Создайте папку для настроек и скопируйте туда шаблон:

```cmd
mkdir secrets
copy .env.example secrets\.env
```

7. Откройте файл `secrets\.env` блокнотом. Вставьте токен вместо значения `TG_BOT_TOKEN` и свой ID вместо `ADMIN_IDS`. Сохраните файл.
8. Запустите бота:

```cmd
python main.py
```

9. В Telegram найдите своего бота по имени, которое давали BotFather, нажмите Start и напишите задачу текстом.

Чтобы бот сам вытаскивал из фразы «кому» и «к какому сроку», поставьте ещё программу Ollama — шаги ниже. Без неё бот всё равно создаст задачу, но формулировку нужно будет подтвердить вручную.

### Если нужен разбор формулировки (Ollama)

1. Скачайте установщик с [https://ollama.com/download](https://ollama.com/download) и установите.
2. В том же чёрном окне введите:

```cmd
ollama pull llama3.1:8b
```

Скачивание модели большое, подождите. Когда закончится, перезапустите бота командой `python main.py`.

## Как пользоваться

1. Напишите боту `/staff` и добавьте сотрудника: имя и его Telegram ID.
2. Отправьте задачу текстом или голосом. Перед созданием бот покажет формулировку — подтвердите её.
3. Исполнитель видит свою карточку и закрывает задачу кнопками.
4. Бот напомнит до срока и напишет, если срок сорван.

Другие команды, если понадобятся: `/tasks` — список, `/log` — журнал, `/new` — новая задача.
